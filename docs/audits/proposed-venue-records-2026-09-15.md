   an 11,500 sq ft outdoor lot with a **children's playground, lawn games, and 500-guest

   omitted, not invented.

5. **Enjay's Pizza is modeled as one venue, "Smokey Joe's (Enjay's Pizza)"**, per the original

8. All Place IDs below (except Ekta and Marrakesh, N/A) come from a live Places API (New) Text
